Developer Integration

Zero-Infrastructure Onboarding

Install the pure-Python sidecar package. It runs as an embedded background thread within your agent worker process. Zero Docker overhead.

1. Install SDK

pip install meshkor

2. Environment Variables (.env)

Configured specifically for your organization:

MESHKOR_ORG_ID=org_kormic
MESHKOR_API_KEY=mk_live_your_secret_key
MESHKOR_HQ_URL=http://44.193.27.158:8080

3. Python Integration Snippet

from meshkor.integrations.kormic import KormicMeshKorIntegration

# 1. Initialize integration (loads MESHKOR_ORG_ID and MESHKOR_API_KEY from environment)
meshkor = KormicMeshKorIntegration()

# 2. Enroll Agent (receives sovereign unforgeable AIN and syncs security tier)
ain = meshkor.enroll_agent(
    agent_class="STU",
    instance_ref="student_agent_01",
    manifest={
        "allowed_tools": ["search", "calc", "db_reader"],
        "max_context_window": 8192
    },
    constitution_hash="sha256_hash_of_constitution_prompt"
)
print(f"Agent enrolled successfully: {ain}")

# 3. Record Actions (automatically hashes payload locally with SHA-256)
# If organization is switched to ENFORCED tier, violations raise MeshKorSecurityBlockException
meshkor.record_event(
    ain=ain,
    action_type="agent_sent_message",
    payload={"query": "Student academic evaluation request"}
)
